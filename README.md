# Образовательные инструменты

Небольшие интерактивные программы, созданные для того, чтобы сделать обучение более наглядным, удобным и доступным.

Проекты разрабатываются и совершенствуются на основе практического опыта использования, с учётом потребностей детей и особенностей самостоятельного обучения.

## Наши программы

### Запись примеров столбиком

Интерактивный инструмент для размещения математических примеров на листе.

Возможности:
- сложение, вычитание, умножение и деление;
- создание примеров вручную и с помощью генератора;
- удобное размещение записей на виртуальном листе;
- работа с мышью и сенсорным экраном;
- сохранение и экспорт результатов.

### Геометрия на листе

Инструмент для наглядного построения геометрических фигур с помощью компьютера.

Позволяет выполнять геометрические построения без необходимости рисовать фигуры от руки на бумаге.
